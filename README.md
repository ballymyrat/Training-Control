# Training Control — Android demo
Created by Ballymyrat Yagdyyev.

Offline demonstration for reviewing navigation, crew profiles, flight hours, and training due dates. It contains fictional records and stores changes on the phone only. **No online accounts, synchronization, verified permissions, or production audit trail.** Do not enter real personal or operational data.

To download the installable APK: GitHub repository > Actions > latest successful 'Build Training Control APK' > Artifacts > Training-Control-Android-APK. Unzip the downloaded artifact and install app-debug.apk. Android may request permission to install from the selected file manager.
